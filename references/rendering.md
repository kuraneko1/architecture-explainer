# Renderer contract

`python3 scripts/diagram.py scene.json --out /path/to/figure --palette jade-violet`

Requires Python, matplotlib, Pillow, and a Japanese-capable font (default Noto Sans CJK JP). Uses code, not image generation. Palette presets are in assets/palettes.json. The same scene may be exported with any preset without moving nodes.

Scene JSON contains canvas [w,h], nodes, captions, edges, frames and optional lines. Nodes have id, box [x,y,w,h], label, optional sublabel, role (neutral/local/global/third/fourth), fontsize and shape (rect/circle). Captions have x,y,text,size,color,ha. Frames have box,role and optional label. Edges have from,to, optional from_side/to_side (top/right/bottom/left), role, dashed, and optional waypoints. Waypoints are routing hints, not a guarantee: if they cause a text collision the router repairs them. Captions/labels are measured before edge rendering; put edge descriptions in captions with enough space and let the router avoid them. Lines are decorative dividers only; do not use them to bypass routing for data edges.

Dense-figure styling: `memory` aliases palette fourth and `modulation` aliases third (including matching soft fills). Node `emphasis: true` uses solid role fill with white text. Edge `width` changes stroke weight; `dashed` differentiates residual paths. Frames can specify `fill` (a palette key) and `fill_alpha` for quiet background bands, while their `role` still sets the outline. Decorative lines accept `width` and `dashed` for a visual key. Frames/bands have no graph semantics. Pure role/fill/weight changes do not change nodes, edges, or routing; adding stage captions may trigger measured rerouting.

The router first tries direct and short orthogonal routes, then a sparse rectilinear visibility graph. It keeps ports fixed, reserves text bounds plus clearance, and includes source/target port stubs in validation. It reserves accepted wires with 7px clearance, protects future terminals, and retries conflicting wires first with alternate tie order (up to three passes). Perpendicular crossings, collinear overlaps and T-contacts outside the common-port stem count as conflicts. Shared graph terminals have a short 24px fan-out/fan-in allowance. Legacy integrations can declare junction coordinates and required route anchors explicitly; never infer intentional junctions from arbitrary internal line crossings. Nonzero final conflicts produce .routing-failure.json and abort image export. No automatic label repositioning is promised. Labels too wide for their nodes or overlapping another label cause a failure for layout repair. Frames are passive groups, not obstacles. Initial port stubs need a little free space: keep labels away from ports.

Outputs: .png, .svg, -outlined.svg, -preview.png, .geometry.json (routes and bounds), .validation.json (including wire_crossings_or_overlaps). The SVG preserves text; outlined SVG avoids missing-font differences on another machine. Both versions are useful and should not be confused. Check status/failure reports before treating an existing PNG as the result of a failed rebuild.
